# 開車模擬器｜慢慢開，平安到

遊戲程式位於 `driving/index.html`。CSS、JavaScript、圖示與道路繪圖全部內嵌，無須安裝套件、連線載入素材或執行建置。

## 開啟遊戲

1. 解壓縮 `driving.zip`。
2. 使用桌面瀏覽器開啟 `driving/index.html`。
3. 手機使用者可透過 GitHub Pages 網址遊玩。介面會依螢幕寬度排列。

畫面按鈕是主要操作方式。鍵盤另支援 ↑ 油門、← 左轉、→ 右轉，以及 Space 煞車。方向燈請另外點擊畫面上的開關；轉向按鈕不會自動打方向燈。

煞車採「點一下踩住，再點一下放開」的操作方式。通過路口後，方向燈會自動關閉。行駛至下一路口需要約 1.5 秒，這段期間踩住煞車會停下；放開後繼續行駛。

累積紀錄儲存在同一個瀏覽器的 localStorage，重新整理後仍會保留。若瀏覽器不允許儲存，遊戲仍能運作，但紀錄只保留到關閉頁面。不同裝置、瀏覽器與網址的紀錄不互通。

## 上傳 GitHub Pages

最簡單的方式是建立名為 `driving` 的公開儲存庫，並把本機 `driving` 資料夾裡面的 **index.html 檔案**放到儲存庫最外層。

1. 登入 GitHub，建立公開儲存庫，名稱例如 `driving`。
2. 選擇上傳檔案，將 `driving/index.html` 上傳成儲存庫根目錄的 `index.html`，提交變更。請先解壓縮；直接上傳 ZIP 不會變成可玩的網站。
3. 前往儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
5. Branch 選擇 **main**，資料夾選擇 **/(root)**，按下 **Save**。
6. 等待發布完成，在 Pages 設定頁點選 GitHub 提供的網站連結。

例如帳號為 `your-name`、儲存庫名稱為 `driving`，網址通常為 `https://your-name.github.io/driving/`。這只是格式範例，並非已發布的網站。

如果你把整個本機 `driving` 資料夾放入另一個儲存庫，遊戲會位於該網站網址的 `/driving/` 路徑。GitHub Pages 的分支發布來源可以選根目錄或 `/docs`，不用把來源設成 `/driving`。

官方說明（2026-10-15 核對）：

- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 修改遊戲金額

用文字編輯器開啟 `index.html`，找到 `<script>` 開頭的 `CONFIG`。可調整每格油價、闖紅燈罰單、維修費與和解費。這些都是遊戲設定金額。

修改後重新上傳同一個 `index.html`，公開網站即可使用同一份規則。建議測試時使用無痕視窗，避免舊的累積紀錄影響試玩結果。

## 驗證範圍

已通過 80 項自動化邏輯情境測試，包含所有起步條件組合、油量邊界、轉彎方向燈、紅燈機率邊界、機車停等、所有停車條件組合、失敗重開、鎖車、成功統計與紀錄保存。

測試以 Node.js 模擬時間、亂數、儲存與畫面元素，並執行實際遊戲 JavaScript 及按鈕事件。此環境未提供可用的瀏覽器驗證工具，尚未做實機瀏覽器操作、畫面截圖或 GitHub Pages 線上驗證。程式沒有外部相依項目，最終仍建議上傳後實際試玩一趟。
