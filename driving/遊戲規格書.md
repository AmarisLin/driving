# 「開車模擬器」遊戲規格書

## 一、基本資訊

這是一個單一 HTML 檔（index.html）的互動開車遊戲。玩家需完成上車準備、道路行駛及停車離開，操作錯誤可能立即失敗，必須重新開始。遊戲不提供完整步驟提示，讓玩家透過試錯了解規則。

## 二、畫面與流程

1. **上車準備：**提供檢查油量、加油、安全帶、煞車、啟動引擎、排檔及手煞車等操作。
2. **起步：**玩家按下油門時，檢查車輛是否符合起步條件。
3. **道路行駛：**途中有三個路口，分別為直行、右轉及左轉，設有紅綠燈與機車禮讓情境。
4. **停車：**抵達終點後，玩家自行操作煞車、手煞車、P 檔及熄火。
5. **下車離開：**玩家下車後可選擇鎖車，再按「離開」完成行程。
6. **結果畫面：**失敗時顯示原因及「重新開始」；成功時才公布累積紀錄。

## 三、遊戲判定規則

### 1. 起步失敗

按下油門時，若未啟動引擎、未切換至 D 檔，或未放開手煞車，立即進入失敗畫面。

顯示：「起步失敗，你忘了啟動引擎／換檔／放開手煞車。」依實際漏做項目顯示原因；同時漏做多項時，一併列出。

### 2. 油量與加油

- 每次重新開始，隨機產生油量。
- 油量以格數表示，按「檢查油量」才會顯示。
- 點擊加油圖案，補至滿格並累計加油費。
- 三格以下未加油就起步，立即進入失敗畫面，顯示：「上路失敗，你的車開到一半沒油了。」
- 超過三格可自行決定是否加油。
- 三格的判定門檻僅寫在程式內，不在玩家畫面、操作說明或提示中公開。本規格書為作者與實作者文件。

### 3. 轉彎與方向燈

未打正確方向燈就轉彎，立即發生車禍並進入失敗畫面。顯示：「開車失敗，你撞到了旁邊的直行車。」同時累計車禍次數、維修費與賠償和解費。

### 4. 闖紅燈

每次闖紅燈，獨立隨機判定：

- **30% 機率：**發生車禍，進入失敗畫面，顯示：「開車失敗，你闖紅燈發生了車禍。」
- **70% 機率：**沒有發生車禍，可以繼續行駛。
- **無論有沒有車禍：**都累計一次闖紅燈及一筆罰單費用。

發生車禍時，另外累計維修費與賠償和解費。

### 5. 機車禮讓

其中一個路口會出現從內側接近的機車。玩家需減速停等，讓機車先行；若直接轉彎與機車碰撞，立即失敗並累計相關事故費用。顯示：「開車失敗，你沒有禮讓機車，發生了碰撞。」

### 6. 停車失敗

玩家按「下車」時，檢查車輛是否已停穩、拉起手煞車、切換 P 檔並熄火。任一項未完成，立即進入失敗畫面。

顯示：「停車失敗，你忘了拉手煞車／切換 P 檔／熄火。」依實際漏做項目顯示原因；未停穩時另列「踩煞車停穩」。

### 7. 忘記鎖車

下車後按「離開」時，若未鎖車，立即進入失敗畫面。顯示：「你的車被偷走了。」同時累計一次被偷車紀錄。

## 四、失敗與重新開始

- 失敗後停止本次遊戲，不能直接修正後繼續。
- 按「重新開始」，回到上車準備畫面，重新產生油量。
- 車輛及道路狀態重置，累積紀錄保留。
- 遊戲途中不顯示累積統計，直到玩家成功完成一趟才公布。

## 五、累積紀錄

程式在背景記錄重開次數、加油總費用、闖紅燈次數及罰單總費用、車禍次數、車禍維修總費用、賠償和解總費用，以及被偷車次數。

各項費用使用可調整的遊戲金額，不代表現實收費標準。每次事件只記錄一次，避免失敗畫面重複計費。

## 六、成功畫面

玩家安全通過三個路口，完成停車、熄火、下車及鎖車後，按「離開」，顯示：「恭喜，你終於成功開完一趟！」

下方公布所有累積紀錄與費用合計，並提供「重新挑戰」按鈕。重新挑戰時清空統計，開始新一輪遊戲。

## 七、製作與技術規範

1. 最終作品整理成單一 `index.html`，放在 `driving` 資料夾內，CSS 與 JavaScript 直接寫在 HTML 內。
2. 網頁包含可操作的遊戲流程、失敗判定、重新開始及累積紀錄。
3. 可將作品上傳至 GitHub，使用 GitHub Pages 公開網站，讓其他人透過網址遊玩。
4. 規格書、程式實作與上傳後的公開網站使用相同的遊戲規則。

## 八、此版本的具體設定

本節補足規格未指定的數值與同時發生事件的處理方式，供後續維護。

| 設定 | 實作 |
| --- | --- |
| 油量範圍 | 每次均勻隨機產生 1～8 格；滿格 8 格 |
| 加油費 | 每補一格 180 元，滿油再次點擊不收費 |
| 罰單 | 每次闖紅燈 2,700 元 |
| 維修費 | 每次事故 18,000 元 |
| 賠償和解費 | 每次事故 36,000 元 |
| 三個路口 | 日光路口直行、花園路口右轉、河畔路口左轉 |
| 機車 | 花園路口；踩煞車停穩並連續停等約 2.2 秒後先行通過 |
| 號誌 | 每個路口隨機以紅燈或綠燈開始；紅燈約 5.2 秒、綠燈約 7 秒 |
| 轉向 | 方向燈需另行操作；通過路口後自動關閉 |
| 踩油門通過路口 | 依該路口既定路線行駛，與對應轉向按鈕使用相同判定 |
| 多項違規同時發生 | 先登記紅燈違規，再依方向燈、機車、紅燈事故的次序顯示失敗原因；同一事故只計一次事故費用 |
| 煞車 | 點一下踩住並停穩，再點一下放開；踩住期間踩油門不會移動 |
| 安全帶 | 可切換並顯示狀態，未另增原規格沒有指定的失敗條件 |
| 紀錄保存 | localStorage；限制儲存時改於記憶體保留，直到頁面關閉 |
| 計數 | 失敗後按下重新開始才增加重開次數；成功後重新挑戰清空所有統計 |

被偷車僅記錄次數，不另加車輛購買費，費用合計由加油、罰單、維修與賠償和解四項組成。加油僅在出發前提供；引擎在出發前或停車場可操作，行駛途中維持運轉。
